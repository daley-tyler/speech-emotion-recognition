# Speech Emotion Recognition project code

See the [project README](../README.md) for purpose, verified tests, actual results and setup. Run the documented commands from the repository root.

`minilearn/` contains the NumPy algorithms. `audio_features.py` extracts 724 acoustic summaries, `evaluate.py` retains the first-pass holdout experiments, and `benchmark.py` provides the matched comparison and nested actor evaluation.

Original weekly notebooks and saved outputs remain in the academic fork and preserved development copies. They are excluded from this release and have not all been rerun. Dataset audio, feature tables and individual experiment predictions also remain outside this repository. See [provenance](../docs/PROVENANCE.md) for the publication scope.
